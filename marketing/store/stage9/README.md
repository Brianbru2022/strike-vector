## Gameplay media

- `screenshots/` contains six captured 1920×1080 gameplay frames.
- `gameplay-trailer-master.webm` is a gameplay-only capture master with no concept-art or marketing-copy frames.
- `gameplay-media-manifest.json` binds every capture to the build and SHA-256 digest.

The WebM is a visual edit master. A final human trailer pass must confirm pacing, encode and audio before upload; the current capture must not be represented as Valve-approved media.
