# Iron Kestrel '87 support

## Getting help

Use the support or community channel on the storefront or distribution page from which Iron Kestrel '87 was obtained. A dedicated public support address must be added here before any standalone commercial distribution that does not provide its own support channel.

## Preparing an issue report

1. Open **System Settings**.
2. Select **Export Issue Report** under Support & Issue Report.
3. Review the downloaded JSON before sharing it.
4. Include the build identifier shown in the Flight Manual and a short description of what happened.

The consumer export contains the build, viewport class, active input type, non-identifying settings and performance snapshot. Internal builds may additionally include up to 20 sanitised local diagnostic sessions. It excludes operation seeds, raw keys, names, contact details, IP addresses and account identifiers. The export remains on the device until the player chooses to share it.

## Common recovery steps

- If offline files are incomplete, open **System Settings**, use **Repair Offline Files**, then reload after the repair completes.
- Use **Export Progress** before moving browsers or clearing site data.
- Save imports display a preview and preserve the previous progression as **Restore Pre-Import Backup**.
- If controls behave unexpectedly, reset the relevant keyboard or gamepad bindings.
- If performance is unstable, select a lower rendering-quality preset or enable reduced effects.
- Campaign and operation data should not be cleared until an issue report has been exported and any needed save evidence has been preserved.

## Supported release environment

The commercial target is the 64-bit Windows 10/11 edition using Microsoft WebView2. The focused demo also supports current desktop and mobile browsers with Canvas, Web Audio, local storage and service-worker support. Keyboard is the only storefront input claim until the controller certification record is approved; compatible gamepad and mobile landscape touch paths remain available for testing. Browser speech is optional and is never required for tactical information.
