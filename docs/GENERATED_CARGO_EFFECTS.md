# Generated cargo and explosion artwork

These deterministic assets were created with OpenAI's built-in image generation mode. Full-resolution sources are retained under `art/source/generated-1987/effects-v2/`; cleaned runtime sprites are bundled under `public/assets/sprites/`.

## Cargo supply freighter prompt

```text
Use case: stylized-concept
Asset type: transparent side-view civilian cargo ship sprite for a painted 2D 1987 Harrier combat game
Primary request: a late-1970s North Atlantic civilian break-bulk cargo freighter carrying deck containers and palletised relief supplies, strict left-facing side profile at the waterline, complete hull, bridge, masts, cranes and cargo visible
Style/medium: realistic hand-painted 2D game asset with detailed weathered hull plating, restrained brush texture and a crisp silhouette matching premium Cold War military artwork
Composition/framing: exactly one complete isolated ship, long low horizontal composition; keel and waterline level; minimal empty space around the vessel
Lighting/mood: cold overcast North Atlantic daylight from upper left, subtle waterline reflection and a narrow contact wake only
Colour palette: weathered navy-blue and rust-red hull, off-white superstructure, muted olive and ochre cargo crates, restrained grime
Background: genuinely transparent alpha background
Constraints: civilian vessel, no weapons, no military markings, no scenery, no ocean background, no checkerboard, no white box, no text, no logo, no watermark, no cropped bow or stern
```
