# Mission 13 generated art archive

Troms Bridgehead uses a deterministic bundled operational panorama. Image generation is never called during play.

## Runtime and source

- Runtime WebP: `public/assets/backgrounds/arctic-bridgehead-operational-v1.webp`
- Full-resolution source: `art/source/generated-1987/norwegian-mission-13-v1/troms-bridgehead-operational-source.png`

The runtime image is quality-84 WebP. It is clipped beneath the authoritative `ARCTIC_BRIDGEHEAD` terrain profile, so the painted sea, shingle, bridge and runway matting cannot create independent collision geometry or floating target anchors.

## Final generation prompt

Built-in image generation mode was used for a wide, side-on 1987 Norwegian amphibious beachhead: cold sea and surf progressing into wet shingle and snow-dusted tundra, a damaged concrete crossing and an expeditionary Harrier FARP. The prompt required coherent painted realism, one lighting direction, no repeated tiles, no people, vehicles, text, logos, border or interface elements.
