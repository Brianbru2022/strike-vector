# AI-assisted content disclosure

## Player-facing disclosure

Iron Kestrel '87 contains pre-generated visual material created with assistance from OpenAI image-generation tools during development. This includes source artwork used for painted environments, aircraft, vehicles, ships, interface illustrations, effects and store key art. The outputs were selected, cleaned, composited, resized, given transparency or contact metadata, and reviewed within the project before being bundled with the game.

Forty-eight foundational aircraft, weapon, impact, environment and warning sounds—including the Pegasus layers, VTOL movement, ejection sequence, aircraft and naval weapons, explosions, servicing ambience, coastal weather, cockpit threat cues, radio transitions and interface feedback—are pre-generated ElevenLabs Sound Effects outputs selected and edited locally. Source candidates, prompts, checksums, selection decisions and reproducible runtime-processing records are archived in the project provenance record. Superseded Sony Woosh ejection candidates are retained only as non-shipping historical evidence.

Eleven original instrumental soundtrack cues are pre-generated Suno outputs created and downloaded under the project owner's paid Premier subscription on 26 September 2026. The project retains embedded Suno generation identifiers, source files, checksums and reproducible loop/loudness processing records. Commercial-use permission does not guarantee copyright protection or exclusivity, so the tracks remain conditional on human listening and similarity review. The planned main-title cue has not yet been supplied.

The game does **not** generate artwork, dialogue, audio or other content with generative AI while it is running. It does not send player prompts or gameplay data to an AI service.

Engineering and editorial work also used OpenAI Codex assistance. This development tooling is not a live player-facing AI system.
