# Known issues

The current build is a development candidate, not a commercial release candidate.

- Windows binaries are not yet code-signed.
- Windows 10/11 installation, update and uninstall checks are pending on clean machines.
- Steam Auto-Cloud conflict and rollback rehearsals are pending in the Steam environment.
- Minimum-spec, three-hour soak and judgement-based accessibility/control sign-offs are pending.
- Store page, product build, legal and title-clearance approvals remain external Stage 9 blockers.

These items are release blockers and must not be represented as completed features or certifications.
